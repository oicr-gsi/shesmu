Olives that use the variables changed to `PATH{path} | URI{uri}` as a `path` or string (_e.g._, `"{path}"` or `std::path::*`) must use `Match` or `std::path_or_uri::to_string`, and olives that build the Vidarr `analysis` parameter must use `PATH{...}` or `std::string::to_path_or_uri`. JSON input files (_e.g._, `.cerberus_fp-input`) must be converted, since these values are now algebraic (`{"type": "PATH", "contents": ["/path"]}`).
