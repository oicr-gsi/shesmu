`std::string::to_path_or_uri` and `std::path_or_uri::to_string` to convert between strings and `PATH{path} | URI{scheme = string, host = string, name = string}`, the type of files that may be remote (_e.g._, `gs://bucket/file`), `std::path_or_uri::file` to get the last element of one as a string, and `std::path_or_uri::to_path` and `std::path_or_uri::to_uri` to get the path of a local file or the fields of a URI as optional values
